# ai-engineering-2026-day2
LoRA format tuning exercise
## Day2 基礎課題：LoRA学習回数の比較

### 実験条件
Qwen3.5-0.8Bを使用し、LoRAの学習回数（num_train_epochs）を20から10に変更した。その他の主要設定は固定し、ランタイムを再起動して学習前後の評価を実施した。

### 実験結果

| 指標 | 20エポック | 10エポック |
|---|---:|---:|
| format_rate | 100% | 100% |
| content_rate | 90.48% | 90.48% |
| 最終Training Loss | 0.014056 | 0.100009 |
| 学習時間 | 228秒 | 111秒 |

### 考察
学習回数を半分にすると、学習時間は約51.3%短縮された。一方、最終Training Lossは増加したものの、21問の評価におけるJSON形式遵守率と内容正解率は変わらなかった。

この結果から、今回の限定された評価条件では、10エポックでも20エポックと同等の回答品質を達成できたと考えられる。

今後は評価問題数を増やし、未知の質問や言い換えに対する汎化性能も確認する必要がある。
